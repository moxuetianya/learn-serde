# 第二十章: 总结与进阶方向

## Serde 学习路线回顾

你已经学完了整个 serde 框架。回顾一下你掌握的知识:

### 第一章-第二章: 概念基础
- Serde 是一个框架,不是数据格式
- serde data model 定义了 28 种抽象类型
- `Serialize` 将 Rust 类型映射到 data model
- `Serializer` 将 data model 转换为字节/字符串

### 第三章-第四章: 序列化
- `Serialize` trait: 只有一个方法,调用恰好一个 Serializer 方法
- `Serializer` trait: 28 个方法 + 7 个复合类型 trait
- 手工实现: `struct`, `enum`, `newtype`, `Vec-like` 等

### 第五章-第七章: 反序列化
- `Deserialize` trait: 创建 Visitor,传递 Deserializer 方法
- `Visitor` trait: ~20 个 visit_* 方法,按值/借用/传递控制
- `Deserializer` trait: 28 个方法,分为 self-describing 和 type-driven
- 辅助 trait: `SeqAccess`, `MapAccess`, `EnumAccess`, `VariantAccess`

### 第八章-第十章: derive 宏
- `serde_derive` 在编译时解析 AST,生成 impl 代码
- 属性系统: 容器级/变体级/字段级三层属性
- 高级模式: `transparent`, `flatten`, `remote`, `tag`, `untagged`

### 第十一章-第十五章: 内部实现
- `Ctxt`: 错误收集器,一次报告所有错误
- `Symbol`: 属性名常量,35 个
- `Name`/`MultiName`: 序列化/反序列化名称管理
- `Container::from_ast()`: 从 syn::DeriveInput 构建内部 AST
- `check.rs`: 10+ 条交叉验证规则
- `replace_receiver()`: Self → 具体类型
- `bound.rs`: 自动生成 trait bounds
- `Content`: untagged enum 的缓冲机制
- 枚举四种 tag 策略的代码生成

### 第十六章-第十七章: 实战
- 完整实现自定义 BinarySerializer
- 完整实现自定义 BinaryDeserializer
- 自定义 KVP 格式的 ser/de roundtrip

## 进阶方向

### 1. 编写生产级数据格式

参考 serde_json 和 postcard 的源码:

```
serde_json:  content-driven (self-describing)
  解析 JSON → Value → 根据需要转换为 Rust 类型

postcard:    type-driven (non-self-describing)
  调用方告知类型 → 直接读写二进制

bincode:     type-driven, configurable endianness
rmp-serde:   MessagePack, content-driven
```

### 2. 性能优化方向

- **零拷贝**: 实现 `visit_borrowed_str`/`visit_borrowed_bytes`
- **预分配**: 利用 `SeqAccess::size_hint` 和 `MapAccess::size_hint`
- **堆分配优化**: 减少 `Content` 的克隆(用于 untagged enum)
- **inline**: 在 Deserializer 方法上添加 `#[inline]`
- **SIMD**: serde_json 使用 simd-json 加速解析

### 3. 深入研究 derive

- 理解 `serde_derive_internals/src/check.rs` 中所有验证规则
- 为新的 serde 属性编写支持(需要修改 `attr.rs` + `check.rs` + 代码生成)
- 研究 `#[serde(deserialize_in_place)]` feature

### 4. 理解其他 serde ecosystem

```
serde_bytes        — &[u8]/Vec<u8> 的高效序列化
serde_repr         — C-like enum 的整数表示
serde_with         — 常用 serde 辅助宏的集合
serde_yaml         — YAML 格式实现
toml               — TOML 格式实现
csv                — CSV 格式,使用 serde flatten
```

### 5. 贡献 serde

- 阅读 CONTRIBUTING.md
- 从 good-first-issue 开始
- 理解 CI 流程和 fuzz 测试
