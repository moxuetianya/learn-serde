# 第十章: 高级模式与特殊属性

**源码参考**: `serde_derive_internals/src/check.rs`, `serde_derive/src/de/enum_*.rs`, `serde/src/private/de.rs`, `serde/src/private/ser.rs`

## 1. `#[serde(transparent)]` —— 透明序列化

```rust
#[derive(Serialize, Deserialize)]
#[serde(transparent)]
struct Meters(f64);
```

序列化时会"穿透"外层,直接序列化内层 `f64`:

```rust
// 约束: 必须有恰好一个非 jumped 字段
// 源码: serde_derive_internals/src/check.rs ~400-440
fn check_transparent(cx: &Ctxt, cont: &mut Container) {
    // 不能用于枚举
    // 不能用于 unit structs
    // 必须有恰好一个非 skipped 字段
    let non_skipped: Vec<_> = fields.iter()
        .filter(|f| !f.attrs.skip_serializing() && !f.attrs.skip_deserializing())
        .collect();
    if non_skipped.len() != 1 {
        cx.error_spanned_by(...);
    }
}
```

生成的代码:

```rust
// 序列化: 直接序列化内层字段,不包裹
impl Serialize for Meters {
    fn serialize<S>(&self, s: S) -> Result<S::Ok, S::Error> {
        self.0.serialize(s)  // 直接用 f64 的 Serialize
    }
}

// 反序列化: 直接反序列化内层类型
impl<'de> Deserialize<'de> for Meters {
    fn deserialize<D>(d: D) -> Result<Self, D::Error> {
        f64::deserialize(d).map(Meters)
    }
}
```

## 2. `#[serde(flatten)]` —— 字段扁平化

```rust
#[derive(Serialize, Deserialize)]
struct S {
    a: i32,
    #[serde(flatten)]
    extra: BTreeMap<String, serde_json::Value>,
}
```

解析 `{"a": 1, "b": 2, "c": 3}` 时:
- `a` 映射到 `S::a = 1`
- `b` 和 `c` 被收集到 `extra` map 中

### flatten 的实现策略

**序列化** (`serde_derive/src/ser.rs`):
```rust
// flatten 字段用 FlatMapSerializer
// 源码: serde/src/private/ser.rs ~1090
// 展开 flatten 字段的序列化结果,合并到父级 map/struct 中

// 生成的代码(概念):
let mut state = serializer.serialize_struct("S", 1)?;
state.serialize_field("a", &self.a)?;
// flatten: 将自己的字段"展开"到父级
FlatMapSerializer::new(&mut state).serialize_struct_sized(&self.extra)?;
state.end()
```

**反序列化** (`serde_derive/src/de/struct_.rs`):
```rust
// 1. 声明字段变量 + 一个 Vec<(Content, Content)> 缓冲区
let mut a: Option<i32> = None;
let mut extra: BTreeMap<String, Value> = BTreeMap::new();

// 2. 遍历 map,已知字段匹配后填入变量,
//    未知字段收集到缓冲区
while let Some(key) = map.next_key::<Field>()? {
    match key {
        Field::a => { a = Some(map.next_value()?); }
        Field::__other => {
            let k: Content = map.next_value()?;
            let v: Content = map.next_value()?;
            extra_buf.push((k, v));
        }
    }
}

// 3. 从缓冲区反序列化 flatten 字段
let extra = BTreeMap::deserialize(
    serde::__private::de::FlatMapDeserializer(content, extra_buf)
)?;
```

## 3. `#[serde(remote = "...")]` —— 远程类型实现

用于为第三方 crate 的类型实现 `Serialize`/`Deserialize`:

```rust
// 定义本地"替身"类型,用相同的字段结构
#[derive(Serialize, Deserialize)]
#[serde(remote = "other_crate::TheirType")]
struct TheirTypeDef {
    #[serde(getter = "their_getter_method")]
    field_name: FieldType,
}

// 在需要的地方:
#[derive(Serialize, Deserialize)]
struct MyStruct {
    #[serde(with = "TheirTypeDef")]
    data: other_crate::TheirType,
}
```

### remote 的实现原理

```rust
// 源码: serde_derive_internals/src/receiver.rs
// replace_receiver: 将 Self 替换为远程类型的完整路径

// 对于 struct S { #[serde(remote = "Other")] ... }
// 生成的 impl:
impl Serialize for Other {  // 注意: 不是 for S!
    fn serialize<S>(&self, s: S) -> ... {
        // self → Other, 字段通过 getter 访问
        Other::their_getter_method(self).serialize(s)
    }
}
```

## 4. 枚举的四种 tag 策略

### 4a. External (默认)

```json
{"Click": {"x": 10, "y": 20}}
{"KeyPress": "a"}
{"Exit": null}
```

最自然的 JSON 表示,但一个额外的 wrapper 对象开销。

### 4b. Internal tag

```rust
#[serde(tag = "type")]
enum Event {
    Click { x: u32, y: u32 },
    KeyPress(char),
}
```

```json
{"type": "Click",   "x": 10, "y": 20}
{"type": "KeyPress", "value": "a"}  // newtype 默认字段名 __field0
```

实现 (`serde_derive/src/de/enum_internally.rs`):

```rust
// 使用 serde::__private::de::TaggedContentVisitor
// 1. deserialize_any → Content (缓冲整个输入)
// 2. 从 Content 中提取 tag
// 3. 根据 tag 选择 variant,用 ContentDeserializer 反序列化
fn deserialize_internally_tagged_enum(...) {
    // 生成的代码大致:
    __deserializer.deserialize_any(
        _serde::__private::de::TaggedContentVisitor::new(
            "type", VARIANTS
        )
    )
}
```

### 4c. Adjacent tag

```rust
#[serde(tag = "t", content = "c")]
enum Event {
    Click { x: u32, y: u32 },
    KeyPress(char),
}
```

```json
{"t": "Click",   "c": {"x": 10, "y": 20}}
{"t": "KeyPress", "c": "a"}
```

实现 (`serde_derive/src/de/enum_adjacently.rs`, 324行,最复杂的枚举策略):

```rust
// 生成的代码概念:
// 1. deserialize_struct("Event", &["t", "c"], AdjacentTagVisitor)
// 2. Visitor 的 visit_map 处理两种情况:
//    a. key 先出现 "t" → 读 tag → 再读 content → 选择 variant
//    b. key 先出现 "c" → 缓冲 content → 再读 tag → 选择 variant
// 3. 使用 DeserializeSeed 处理延迟决策
```

### 4d. Untagged

```rust
#[serde(untagged)]
enum Event {
    Click { x: u32, y: u32 },
    KeyPress(char),
}
```

```json
{"x": 10, "y": 20}  // 匹配到 Click
"a"                  // 匹配到 KeyPress
```

实现 (`serde_derive/src/de/enum_untagged.rs`):

```rust
// 1. 先将输入缓冲为 Content
// 2. 按顺序尝试每个 variant 的 deserializer
// 3. 第一个成功的结果被采用
// 约束: untagged variant 必须在最后

fn deserialize_untagged_enum(...) {
    let content = Content::deserialize(deserializer)?;
    // 尝试每个 variant
    let deserializer = content.into_deserializer();
    // Ok(Try1) → 返回
    // Err(_) → 丢弃错误,尝试下一个
    // Ok(Err(TryLast)) → 最后一个失败,返回错误
}
```

## 5. `#[serde(into)]` / `#[serde(from)]` / `#[serde(try_from)]`

类型转换模式:

```rust
#[derive(Serialize)]
#[serde(into = "String")]
struct UserId(u64);
// 序列化时: String::from(self).serialize(s)

#[derive(Deserialize)]
#[serde(from = "String")]
struct UserId(u64);
// 反序列化时: String::deserialize(d).map(UserId::from)

#[derive(Deserialize)]
#[serde(try_from = "i32")]
enum State { On, Off }
// 反序列化时: i32::deserialize(d).and_then(State::try_from)
```

## 6. conditional skipping

```rust
#[derive(Serialize)]
struct S {
    #[serde(skip_serializing_if = "Option::is_none")]
    optional: Option<String>,

    #[serde(skip_serializing_if = "Vec::is_empty")]
    items: Vec<i32>,
}
```

生成的代码:

```rust
fn serialize<S>(&self, s: S) -> Result<S::Ok, S::Error> {
    let mut state = s.serialize_struct("S", /* dynamic len */)?;
    // 对于有 skip_serializing_if 的字段:
    if !Option::is_none(&self.optional) {
        state.serialize_field("optional", &self.optional)?;
    }
    // ...
}
```

## 7. `#[serde(borrow)]` —— 零拷贝反序列化

```rust
#[derive(Deserialize)]
struct S<'a> {
    #[serde(borrow)]
    name: &'a str,     // 直接从 deserializer 借用
    #[serde(borrow)]
    data: Cow<'a, str>, // Cow 支持零拷贝
}
```

生成的 `Deserialize` 实现会有 `'de` 生命周期绑定:

```rust
impl<'de> Deserialize<'de> for S<'de> {
    // 'a 被绑定到 'de,允许 visit_borrowed_str
}
```
