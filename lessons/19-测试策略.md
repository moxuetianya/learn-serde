# 第十九章: 测试策略与 serde_test

**源码参考**: `test_suite/tests/*.rs`, `serde_core/src/de/value.rs`

## serde_test crate

`serde_test` 是测试 serde 实现的官方测试库,提供了**无格式依赖**的测试方式:

```rust
use serde_test::{assert_tokens, Token};

// Token 枚举是 serde 数据模型的直接映射
#[derive(Debug, PartialEq)]
enum Token {
    Bool(bool),
    I8(i8), I16(i16), I32(i32), I64(i64),
    U8(u8), U16(u16), U32(u32), U64(u64),
    F32(f32), F64(f64),
    Char(char),
    Str(&'static str),
    BorrowedStr(&'static str),
    String(&'static str),
    Bytes(&'static [u8]),
    BorrowedBytes(&'static [u8]),
    ByteBuf(&'static [u8]),
    None,
    Some,
    Unit,
    UnitStruct { name: &'static str },
    UnitVariant { name: &'static str, variant_index: u32, variant: &'static str },
    NewtypeStruct { name: &'static str },
    NewtypeVariant { name: &'static str, variant_index: u32, variant: &'static str },
    Seq { len: Option<usize> },
    Tuple { len: usize },
    TupleStruct { name: &'static str, len: usize },
    TupleVariant { name: &'static str, variant_index: u32, variant: &'static str, len: usize },
    Map { len: Option<usize> },
    Struct { name: &'static str, len: usize },
    StructVariant { name: &'static str, variant_index: u32, variant: &'static str, len: usize },
    Enum { name: &'static str },
    // ...
    SeqEnd, TupleEnd, TupleStructEnd, TupleVariantEnd,
    MapEnd, StructEnd, StructVariantEnd,
}
```

## 三种断言宏

### assert_tokens —— 完整 roundtrip

```rust
use serde_test::{assert_tokens, Token};

#[derive(Serialize, Deserialize, PartialEq, Debug)]
struct Point { x: i32, y: i32 }

assert_tokens(
    &Point { x: 1, y: 2 },
    &[
        Token::Struct { name: "Point", len: 2 },
        Token::Str("x"),
        Token::I32(1),
        Token::Str("y"),
        Token::I32(2),
        Token::StructEnd,
    ],
);
// 验证: 序列化 Point 产生这些 tokens
//       AND 反序列化这些 tokens 得到相同的 Point
```

### assert_ser_tokens —— 仅序列化

```rust
use serde_test::assert_ser_tokens;

assert_ser_tokens(
    &42u32,
    &[Token::U32(42)],
);
// 仅验证序列化方向
```

### assert_de_tokens —— 仅反序列化

```rust
use serde_test::assert_de_tokens;

assert_de_tokens(
    &Point { x: 1, y: 2 },
    &[
        Token::Seq { len: Some(2) },
        Token::I32(1),
        Token::I32(2),
        Token::SeqEnd,
    ],
);
// Point 可以从序列格式反序列化(按位置)
// 也可以从 map 格式反序列化(按字段名)
assert_de_tokens(
    &Point { x: 1, y: 2 },
    &[
        Token::Map { len: Some(2) },
        Token::Str("y"),
        Token::I32(2),
        Token::Str("x"),
        Token::I32(1),
        Token::MapEnd,
    ],
);
```

### 错误断言

```rust
use serde_test::{assert_de_tokens_error, assert_ser_tokens_error};

// 反序列化错误
assert_de_tokens_error::<Point>(
    &[
        Token::Struct { name: "Point", len: 2 },
        Token::Str("x"),
        Token::I32(1),
        Token::StructEnd,  // 缺少 y!
    ],
    "missing field `y`",  // 错误消息
);

// 类型错误
assert_de_tokens_error::<i8>(
    &[Token::I16(128)],  // 128 超出 i8 范围
    "invalid value: integer `128`, expected i8",
);
```

## 测试模式详解

### 模式 1: 对所有标准库类型做 roundtrip

```rust
// test_ser.rs 示例
#[test]
fn test_bool() {
    assert_tokens(&true, &[Token::Bool(true)]);
    assert_tokens(&false, &[Token::Bool(false)]);
}

#[test]
fn test_option() {
    assert_tokens(&None::<i32>, &[Token::None]);
    assert_tokens(&Some(1), &[Token::Some, Token::I32(1)]);
}

#[test]
fn test_string() {
    assert_tokens(&"hello", &[Token::Str("hello")]);
    assert_tokens(&"hello".to_owned(), &[Token::String("hello")]);
}
```

### 模式 2: 条件跳过测试

```rust
// 某些测试只在特定 feature 下运行
#[cfg(feature = "std")]
#[test]
fn test_hashmap() {
    let mut map = HashMap::new();
    map.insert("a", 1);
    assert_tokens(&map, &[
        Token::Map { len: Some(1) },
        Token::Str("a"), Token::I32(1),
        Token::MapEnd,
    ]);
}
```

### 模式 3: 编译时测试

```rust
// test_gen.rs: 不运行时断言,只要编译通过即可
#[test]
fn test_compile_generic_types() {
    #[derive(Serialize, Deserialize)]
    struct S<T> { value: T }
    // 通过编译即测试通过
}

#[test]
fn test_compile_complex_bounds() {
    #[derive(Serialize, Deserialize)]
    struct S<T: Clone + Default + Serialize + DeserializeOwned> {
        value: Vec<T>,
    }
}
```

## serde 自身的测试: de::value 模块

serde_core 提供了 `de::value::*` 作为 Deserializer 的最小实现:

```rust
// 测试中可以直接用 value deserializers:
use serde::de::value::{BoolDeserializer, I32Deserializer, Error};

let d = I32Deserializer::<Error>::new(42);
let result: i32 = i32::deserialize(d)?;

// SeqDeserializer 从迭代器构造序列:
let d = SeqDeserializer::<_, Error>::new(vec![1, 2, 3].into_iter());
let result: Vec<i32> = Vec::deserialize(d)?;
```

### 测试序列化: `__private_serialize!` 和 `__serialize_unimplemented!`

在 `serde_core/src/private/doc.rs` 中,为文档演示提供了辅助宏:

```rust
// 创建一个假的 Serialize trait 用于文档测试
macro_rules! __private_serialize! {
    () => {
        trait Serialize {
            fn serialize<S>(&self, serializer: S) -> Result<S::Ok, S::Error>
            where S: Serializer;
        }
    };
}

// 快速 stubs 出所有 Serializer 方法
macro_rules! __serialize_unimplemented {
    ($($t:ident)*) => {
        $(__serialize_unimplemented_method!($t);)*
    };
}
```
