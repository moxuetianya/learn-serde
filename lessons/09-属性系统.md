# 第九章: derive 属性系统的完整解析

**源码参考**: `serde_derive_internals/src/attr.rs` (1818 行)

## 属性层次结构

Serde 属性分为三个层次:

```
#[serde(...)]     // 容器级 (struct/enum 上)
    struct S {
        #[serde(...)]  // 字段级
        field: T,
    }

#[serde(...)]     // 变体级 (enum variant 上)
enum E {
    #[serde(...)]  // 变体级
    V {
        #[serde(...)]  // 变体字段级
        field: T,
    }
}
```

## rename_all 规则

```rust
// 源码: serde_derive_internals/src/case.rs
pub enum RenameRule {
    None,
    LowerCase,
    UpperCase,
    PascalCase,
    CamelCase,
    SnakeCase,
    ScreamingSnakeCase,
    KebabCase,
    ScreamingKebabCase,
}

// 使用:
#[serde(rename_all = "camelCase")]
enum MyEnum {
    FooBar,       // → "fooBar"
    BazQux,       // → "bazQux"
}

// 字段默认 snake_case:
#[serde(rename_all = "camelCase")]
struct S {
    foo_bar: i32, // → "fooBar"
}

// 变体默认 PascalCase!!!
// 源码: case.rs ~145
fn apply_to_variant(&self, variant: &str) -> String {
    match self {
        RenameRule::None => variant.to_owned(),
        RenameRule::PascalCase => /* 保持不变,因为变体默认就是 PascalCase */,
        // ...
    }
}

fn apply_to_field(&self, field: &str) -> String {
    match self {
        RenameRule::None => field.to_owned(),
        RenameRule::SnakeCase => /* 保持不变,因为字段默认就是 snake_case */,
        // ...
    }
}
```

## 属性解析架构

### Attr / BoolAttr / VecAttr 类型

```rust
// 源码: serde_derive_internals/src/attr.rs ~80-150

// 单值属性,重复会报错
struct Attr<'c, T> {
    cx: &'c Ctxt,
    name: Symbol,
    value: Option<T>,
}

// bool 属性快捷方式
struct BoolAttr<'c>(Attr<'c, ()>);

// 多值属性,at_most_one() 返回单值
struct VecAttr<'c, T> {
    cx: &'c Ctxt,
    name: Symbol,
    values: Vec<T>,
}

impl<'c, T> VecAttr<'c, T> {
    fn at_most_one(mut self) -> Option<T> {
        if self.values.len() > 1 {
            self.cx.error_spanned_by(/* .. */, "duplicate attribute");
        }
        self.values.pop()
    }
}
```

### 解析入口

```rust
// 容器级属性解析
// 源码: serde_derive_internals/src/attr.rs ~300-500
impl Container {
    fn from_ast(cx: &Ctxt, item: &DeriveInput) -> Self {
        let mut rename = Attr::none(cx, RENAME);
        let mut transparent = BoolAttr::none(cx, TRANSPARENT);
        let mut tag = Attr::none(cx, TAG);
        let mut content = Attr::none(cx, CONTENT);
        let mut untagged = BoolAttr::none(cx, UNTAGGED);
        // ...

        // 遍历所有 #[serde(...)] 属性
        for attr in &item.attrs {
            if attr.path().is_ident("serde") {
                let _ = attr.parse_nested_meta(|meta| {
                    if meta.path == RENAME {
                        rename.set(cx, meta.value()?.parse()?);
                    } else if meta.path == TRANSPARENT {
                        transparent.set(cx, ());
                    } else if meta.path == TAG {
                        tag.set(cx, meta.value()?.parse()?);
                    } else if meta.path == UNTAGGED {
                        untagged.set(cx, ());
                    }
                    // ...
                    Ok(())
                });
            }
        }

        Container {
            rename: rename.get(),
            transparent: transparent.get(),
            tag: decide_tag(tag.get(), content.get(), untagged.get()),
            // ...
        }
    }
}
```

## tag 策略决策

```rust
// 源码: serde_derive_internals/src/attr.rs ~180-210
fn decide_tag(
    tag: Option<Name>, content: Option<Name>, untagged: bool
) -> TagType {
    match (tag, content, untagged) {
        // #[serde(untagged)]
        (None, None, true)    => TagType::None,

        // #[serde(tag = "type")]
        (Some(tag), None, _)  => TagType::Internal { tag },

        // #[serde(tag = "t", content = "c")]
        (Some(tag), Some(content), _) => TagType::Adjacent { tag, content },

        // 默认: external
        (None, None, false)   => TagType::External,
        // ...
    }
}
```

```rust
// 枚举 tag 策略对比
enum TagType {
    External,                        // {"Variant": value}
    Internal { tag: Name },          // {"type": "Variant", ...fields}
    Adjacent { tag: Name, content: Name }, // {"t": "Variant", "c": value}
    None,                            // value (无 tag, 自己匹配)
}
```

## Trait bounds 生成

```rust
// 源码: serde_derive/src/bound.rs
// 自动生成 where 子句

// 对于:
struct S<T> { value: T }

// 生成的 impl:
// impl<T: Serialize> Serialize for S<T>
//
// 对于:
#[serde(bound = "")]
struct S<T> { value: T }
//
// 生成的 impl(无 auto bound):
// impl<T> Serialize for S<T>

// 对于:
#[serde(bound(serialize = "T: MySerialize", deserialize = "T: MyDeserialize"))]
struct S<T> { value: T }
//
// 分别生成:
// impl<T: MySerialize> Serialize for S<T>
// impl<T: MyDeserialize> Deserialize<'de> for S<T>
```
